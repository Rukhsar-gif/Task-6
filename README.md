# BMI Calculator

A responsive BMI Calculator created as **Task 6** of my
**Web Development Internship at Veda Technology**.

## 📌 Project Overview

This project is a simple browser-based BMI calculator that allows
users to enter their height and weight and calculate their Body Mass
Index (BMI).

After calculation, the application displays the BMI value along with
its corresponding category.

The project demonstrates form handling, JavaScript calculations,
functions, validation, conditional statements, and DOM updates.

## 🎯 Objective

The objective of this task was to practice:

- Form handling
- JavaScript calculations
- JavaScript functions
- Input validation
- Conditional statements
- DOM manipulation
- Displaying dynamic results
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Height input in centimetres
- Weight input in kilograms
- BMI calculation
- BMI rounded to two decimal places
- BMI category display
- Validation for empty inputs
- Validation for invalid numeric inputs
- Rejection of zero and negative values
- Reset button
- Enter-key calculation
- Responsive design
- Clean and simple interface
